¿Qué es necesario para que tengamos acceso real a tus redes sociales?

Para que el sistema lea en tiempo real los seguidores, publicaciones y mensajes sin intervención manual, hace falta conectar:

1. TikTok (Login Kit / Display API):

Ingresar a developers.tiktok.com, registrar la app con permisos user.info.stats y generar el nuevo TIKTOK_ACCESS_TOKEN permanente.

2. Instagram (Meta Graph API):

Convertir la cuenta a Perfil Profesional/Empresarial, vincularla a una Página de Facebook y habilitar permisos instagram_basic y pages_read_engagement en Meta Developers.

3. YouTube (Google Data API v3):

Habilitar la YouTube Data API v3 en Google Cloud Console y reautorizar el OAuth agregando el alcance https://www.googleapis.com/auth/youtube.readonly.
